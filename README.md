# CoursePilot-custom

[CoursePilot](https://github.com/wansui976/CoursePilot) 的**个人自改版**——把课程视频变成记得住的东西，并在原版基础上做了大量省钱与效率优化。

基于原版 MIT 许可，保留原作者版权；本仓库为自用增强分支，版本号 `0.4.1`（应用名 `course-ai-custom`）。

## 与原版的主要区别

### 💰 省钱优化（核心）

| 改动 | 说明 |
|---|---|
| **默认关闭课件提取** | 导入后默认不提取课件、不做 OCR，AI 只喂讲稿，token 减少约 75% |
| **OCR 噪音过滤** | 课件开启时也过滤纯符号、超短碎片、水印词（关注/点赞/扫码等） |
| **自动生成产物开关** | 章节/摘要/笔记/测验/脑图可逐个开关（设置里），不需要的不生成 |
| **今日消费精确计费** | 按 DeepSeek 官方峰谷价（空闲/高峰）+ 缓存命中折扣折算，非粗略估算 |

### 📊 DeepSeek 状态面板

侧边栏底部常驻面板：**余额**（`/user/balance`）、**今日消费金额**、**峰谷时段进度条**（工作日 9-12/14-18 高峰，周末平价，跨周标注「周一 09:00 转峰时」）。

### 🗂 视频管理增强

- **处理状态圆点**：缩略图左上角红/绿/蓝圆点（未处理=红、已处理=绿、处理中=蓝）
- **智能重命名**：从标题提取 `p序号-章节-主题-作者`，序号覆盖完整则保留、缺 p 则重编号，作者去重、分割线精简，可预览/撤销
- **自动排序**：先按作者分组 → 组内按序号 → 无序号按章节
- **批量操作**：多选后批量处理、批量生成各产物（下拉勾选）

### 🔧 稳定性

- 并发默认 1（避免本地 OCR 抢 CPU 卡顿）
- `build.rs` 自动复制 sidecar 二进制到 exe 目录（修复 dev 下 `binary not found`）

## 🆕 与原版同步（v0.4.1）

- **应用内一键更新**：原版新版本提示里多了「立即更新」（下载、校验签名、安装、重启）。**自改版已关闭这条**，避免被原版安装包覆盖；想更新原版内容请重新合并源码。
- **本地 OCR 升级**：桌面可选 PaddleOCR PP-OCRv6（约 30 MB，全程离线），中文课件比 Tesseract 明显更准；macOS 仍可用系统 Vision。
- **更准的本地语音识别**：桌面可选 Qwen3-ASR 1.7B，普通话错字比 0.6B 少约六分之一，建议有显卡时用。
- **AI 花费看得见**：设置 → 大模型 → 用量与花费，本月花费按用途 / 课程 / 模型拆分，可设每月预算，到了就暂停自动生成。
- **批量处理**：多选后可以一次「开始处理」（选中的文件夹连同子文件夹里没处理的都排进队列）。
- **播放器**：Windows 上音量可到 200%，方向键调音量有提示，每门课记住自己的音量。
- **界面打磨**：统一缓动、进出视频共享元素过渡、骨架屏、队列「最近完成」、首页限宽居中、没封面的课程有占位封面等。
- **修复**：处理完的视频会自己从队列消失（不再停在 100%）；Mac 上倍速播放不再一卡一卡、吞字。

## 与原版一致的部分

处理流水线（ffmpeg → 本地 ASR/OCR → DeepSeek 生成）、课程问答、间隔复习、字幕纠错等核心功能均与原版相同。完整项目说明见 [README.original.md](README.original.md)（原版 README 备份）。

## 构建

```bash
cd course-ai
pnpm install
pnpm tauri build   # 需要 Rust 工具链 + 前端依赖
```
